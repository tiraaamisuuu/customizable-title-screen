# Customizable Title Screen

A client-side Fabric mod for Minecraft Java Edition 26.2 that lets players choose their own title-screen background and visually arrange the menu controls.

## Target

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 or newer
- Java 25
- Client-side only

## Goals

- Use a local PNG or JPEG as the title-screen background.
- Reposition, resize, align, show, or hide menu elements in a visual editor.
- Support named layout profiles and different resolutions or GUI scales.
- Recover safely from missing images and invalid configuration files.
- Remain entirely client-side.

## Status
