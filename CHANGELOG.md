# Changelog

## 1.0.0 - 2026-08-30

- Initial release for Minecraft 26.2.
- Local background import with five fit modes and visual adjustments.
- Drag-and-drop title layout editor with snapping, profiles, undo, redo, and safe reset.
- Atomic, versioned JSON persistence with backup recovery and profile import/export.
- Optional Mod Menu integration and emergency editor/reset shortcuts.
